# Online Food Ordering System – CI/CD & Kubernetes

Backend-only FastAPI project for restaurant, menu and order management.

Ports:
- API: 3001
- Grafana: 3002
- Internal API: 8000

Features:
- Restaurant management
- Menu management
- Order management
- Automated tests
- Docker
- Kubernetes
- ConfigMap and Secret
- Prometheus and Grafana
- Logging
- Security checks
- Rollout history and rollback support
